# Historica Arcanum → D&D 5.5e (2024) conversion

A 5.5e-compatible mirror of the Historica Arcanum: City of Crescent `.ttrpg`
files, run through WotC's *Converting to SRD 5.2.1* procedure, encoded as
`titterpig-dsl/bridges/0.4/dnd5e-to-dnd5.5e-0.4-srd-conversion.bridge`.

Generated by `a-gibbous-moon-support/scripts/convert_historica_5_5e.py` — this
whole directory is regenerated on each run, so edit the script, not the files.

## Applied automatically (safe, deterministic, verbatim-preserving)
Transforms touch only value strings, never entity-name literals (`^"…"`), so no
DEF name or `EXTENDS` reference changes. Verified: all 11 files parse and the
validator reports the same issue count as the source, file for file.

- **Capitalization** (bridge step 3): damage types before "damage", conditions
  in guarded frames, Advantage/Disadvantage, Bonus Action, Reaction,
  Concentration, Short Rest/Long Rest, Hit Points/Temporary Hit Points.
- **New Name** (step 1): "Hit Dice" → "Hit Point Dice".
- **Module header** retargeted to `EXTENDS "Dnd5_5e_Core_Base"`.

## Step-2 structural changes applied as owner design decisions
Guarded patches in the script (each asserts a single match):

- **Circle of Nazar (Druid — Miray).** Level-2 grant made paltry, the rest moved
  up to level 3. Level 2: protection from evil and good; Level 3: avicenna,
  lesser restoration, detect djinni; 5/7/9 unchanged.
- **Djinnmaster (Warlock — Sidra).** "Pact of the Eye" rehomed as the invocation
  "Invocation of the Eye".
